# scripts

Two Windows batch utilities, shown as-is.

- `Control-Scroll-y-Touchpad.bat`: console menu that toggles a mouse scroll filter and one touchpad. It elevates through UAC and targets a single hardware ID; it is machine-specific.
- `CRM.bat`: start and stop menu for a local dev stack (portable Postgres, API, Next.js app). Requires `CRM_ROOT` and `CRM_PG`; the launched project is not included.
